ABOUT THIS RUN

How this little world runs

The interface, scene, and rules engine are implemented separately. Each input is computed by the active kernel, and the interface renders the returned state.

These games probe rule generation and execution. Their presentation was assembled through a human-directed Codex workflow and is not evidence of end-to-end game generation.
