Foundation Models and LLM Agents for Games

How pretrained language, vision-language, and multimodal models become players, teammates, non-player characters, and generalist interactive agents.

Direct answer

Foundation models and LLM agents for games use pretrained language, vision-language, or multimodal models to interpret game observations, reason about goals, plan actions, communicate, and control characters. They range from agents specialized for one game to generalist systems that operate across many environments through text, pixels, APIs, keyboard and mouse input, or native controllers. Language models can supply high-level plans, tool selection, memory, and dialogue, while learned policies or control modules translate those decisions into timely actions. Important research questions include how an agent grounds language in game state, handles partial information, learns unfamiliar rules, adapts at test time, and coordinates with human or AI partners. Strong performance in one interface does not automatically transfer to another: a model that explains a strategy may still fail to execute it under real-time constraints. Evaluation therefore considers task completion, progress, efficiency, robustness to changed appearance or controls, memory across long episodes, and cooperative behavior. NPCs and teammates add another requirement: their actions and messages must remain useful, legible, and consistent with the shared game state.

This topic is surveyed in AI for Games in the Foundation Model Era.

Evidence

What should evaluation establish?

A convincing agent evaluation separates reasoning from execution and names what changed between training and testing. It should show whether competence survives new visuals, controls, rules, goals, partners, or interaction budgets—not only whether the model can describe the right move.

  • Completion, progress, and action efficiency
  • Transfer across games and interfaces
  • Memory and adaptation over long episodes
  • Coordination with people or other agents
